# Bachelor House Manager v6.2.3

## Included

- Mobile-first single-room cinematic startup using the 3840×2160 housemate scene.
- Cinematic camera pan/zoom keeps all five housemates visibly working together in the same room.
- Removed the startup scene-dot/progress/loading UI from the visual frame; the embedded Start control remains on desktop, with a dedicated touch Start control on mobile.
- Member sidebar no longer exposes Security.
- Security is restricted server-side to the house creator and shows personal account/device/security activity scoped to that creator.
- Expense creation remains available to every member.
- Only the house creator can edit or delete current-month expenses; archived expenses remain locked.
- Replaced the unreliable WhatsApp test action on Member cards with a mobile-friendly Send SMS action that opens the device SMS composer with a prefilled message.
- Expense edit/delete actions and backend routes are house-scoped and creator-protected.

## Verification

- Backend source passed `node --check`.
- Full frontend `npm install` / Vite production build was not completed in the packaging environment because the dependency install timed out.
